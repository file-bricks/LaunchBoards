## 1. Target Personas & Use Cases

1. **The Multi-Project Developer:**
   - Problem: Desktop icons are cluttered with disparate tools, batch scripts, IDE shortcuts, and dev servers.
   - Solution: Dedicated tabbed boards (e.g., "Web Dev", "Data Science", "Embedded") switchable with one click.
   - Key Hook: Zero background overhead, instantaneous launch, no electron bloat.

2. **The Power Desktop User:**
   - Problem: Windows Start menu requires typing full names or navigating multi-level menus.
   - Solution: Visual, drag-and-drop workspace launchpad organized by context of use.
   - Key Hook: Clean PySide6 native look, draggable reordering, persistent tab state.

3. **The Privacy-Conscious Professional:**
   - Problem: Modern app launchers and command bars require cloud accounts, track telemetry, or ping external servers.
   - Solution: 100% offline, zero network egress, local QSettings storage.
   - Key Hook: `INV-LOCAL-01` (Zero Network Egress) and `INV-LOCAL-02` (Unprivileged RunAsInvoker).
